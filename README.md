### API-тестирование в Postman

В рамках практики я выполнил следующие проверки:
- GET /users — получение списка пользователей.
- GET /users/1 — получение пользователя по ID.
- GET /users/99999 — проверка запроса к несуществующему пользователю.

### Результаты
- Успешные запросы возвращают статус 200 OK.
- Запрос к несуществующему пользователю возвращает статус 404.
